# STM32N6570-DK FSBL

`stm32n6570-dk-ai_fsbl.hex` is the official FSBL image currently used by the
STM32N6570-DK sample. It was copied from:

```text
ref/STM32N6_Survivor_Detection/Binaries/ai_fsbl.hex
```

The image contains absolute Intel HEX addresses for the external NOR FSBL
region beginning at `0x70000000`. It is intended for the following layout:

- FSBL: `0x70000000`
- LRUN application: `0x70100000`
- BOOT0: LOW
- BOOT1: LOW

The application and model images are still generated by `sample-ai`; this
directory only owns the board-level FSBL image.
